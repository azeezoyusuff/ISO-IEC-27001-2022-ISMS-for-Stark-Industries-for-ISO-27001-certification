## ISO-IEC-27001-2022-ISMS- Development-for-Stark-Industries-for-ISO-27001-certification

## Purpose

To Build a complete ISO/IEC 27001:2022 ISMS from scratch for a small US-based software company developing a SaaS marketing application 

## Goal

To achieve ISO27001 certification with the scope including the SaaS product to improve sales and customer trust.

## My Role

As a Cyber Security GRC Analyst, I was tasked to build an ISMS, from start to finish, and help the organization achieve ISO 27001 certification. The scope of the ISMS is strictly for the newly developed SaaS application.

## Client Information

| Item | Information |
| -----| ----------- |
| Name | Stark Industries Inc. |
| Location | New York City, New York | 
|  Product | A SaaS platform offering marketing automation tools for small businesses. The application is hosted on Amazon AWS |
| Scope    |  The development, deployment, and management of the Stark Industries platform |
| Customer Demand | Prospective clients require ISO 27001 certification as a condition for procurement
